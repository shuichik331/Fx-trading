# 実践トレードプラン（15分足・5分足限定・月10万円目標）

対象: **ゴールド（XAU/USD）のみ**。5分足・15分足だけで取引し、以下の2パターンに当てはまった時だけエントリーする。それ以外の値動きは「様子見」。

`reports/analysis_report.md`（全32パターンのバックテスト）と`reports/cost_adjusted_results.csv`（スプレッド差引後の実質期待値）から、**15分足・5分足に限定した場合にコスト差引後もプラスの実質期待値を維持した銘柄はゴールドのみ**（ドル円は15分足・5分足のどのパターンも実質マイナス）。その中からさらに2パターンに絞り込んだ。

---

## 採用する2パターン

### パターンA（主力）: ゴールド 15分足 ドンチアン・ブレイクアウト

- **実質期待値**: +0.135R／トレード（コスト差引後）
- **頻度**: 月あたり約86回シグナル（サンプル198件・最も統計的に頑健）
- **エントリー条件**:
  1. 直近20本（15分足なので約5時間）の高値・安値のレンジを引く
  2. 終値がそのレンジの高値を上抜けたら → 次の15分足の始値で**買い**
  3. 終値がそのレンジの安値を下抜けたら → 次の15分足の始値で**売り**
- **チャート上の見た目**: 一定のレンジで揉み合っていた後、勢いよくレンジを実体で抜けるローソク足。TradingViewで20期間のDonchian ChannelまたはHighest/Lowestインジケーターを表示すると視覚的に判断しやすい。

### パターンB（補助）: ゴールド 5分足 RSI逆張り

- **実質期待値**: +0.335R／トレード（コスト差引後、最も高いが**サンプル38件とやや少なめ**なので継続検証が必要）
- **頻度**: 月あたり約16.5回
- **エントリー条件**:
  1. 大局トレンドをEMA200（5分足）で確認
  2. 上昇トレンド中（終値がEMA200より上）に、RSI(14)が30を下から上に抜けたら → 次の5分足の始値で**買い**（押し目からの反発）
  3. 下降トレンド中（終値がEMA200より下）に、RSI(14)が70を上から下に抜けたら → 次の5分足の始値で**売り**（戻りからの再下落）
- **チャート上の見た目**: 大きな流れに沿った押し目/戻りで一時的に売られ過ぎ・買われ過ぎになり、そこから反発するところ。

### 両パターン共通のリスク管理

| 項目 | ルール |
|---|---|
| 損切り | エントリー時点のATR(14)×1.5 |
| 利確 | エントリー時点のATR(14)×3.0（リスクリワード1:2） |
| 最大保有 | 20本（15分足なら約5時間、5分足なら約100分）で未決着なら成行決済 |
| 同時ポジション | パターンA・Bが同時に同方向シグナルを出しても、**ゴールドの実質エクスポージャーは合算で管理**（両方1%リスクを取ると合計2%相当の同方向リスクになるため、上限を決めておく） |
| 除外パターン | 5分足ドンチアン・ブレイクアウト（実質期待値ほぼゼロ）、ドル円の全パターン（実質マイナス）はこの計画では**使わない** |

`src/signal_scanner.py` を実行すると、直近の確定足でパターンA・Bどちらかの条件が今まさに成立しているかをチェックできる（エントリー価格帯・損切り・利確の目安も表示）。

## 月10万円に必要な資金の試算

`src/position_sizing.py` の期待値ベース計算（あくまで平均値、実際の月次結果はブレる）。

| リスク/トレード | パターンAのみ 必要資金 | パターンA+B併用 必要資金 |
|---:|---:|---:|
| 0.5% | 約172万円 | 約117万円 |
| 1.0% | 約86万円 | 約58万円 |
| 1.5% | 約57万円 | **約39万円** |
| 2.0%（上限目安） | 約43万円 | 約29万円 |

**読み方**: パターンAだけに絞るなら、1%リスクで口座資金約86万円あれば期待値ベースで月10万円に届く計算。パターンBも併用すれば、より少ない資金（1%リスクで約58万円）で同じ目標に届く——ただしパターンBはサンプルが少ないため過信は禁物で、当面は**パターンAをメイン、パターンBはロットを小さめにして併用**するのが現実的。

前回の「月100万円」試算（口座数百万〜1千万円規模が必要）と比べると、**月10万円という目標は今回の少額運用プラン（30〜90万円程度の口座）と整合的**で、無理なリスクを取らずに狙える水準になっている。

## 運用ルール

1. **リスクは1トレード1〜1.5%を目安**（2%を超えない）。`src/signal_scanner.py`が出す損切り幅とATRから、`README.md`記載のロット計算式で都度サイズを決める。
2. **シグナルが出ていない時間帯はトレードしない。** 「何か動きがありそうだから」で無理にエントリーしない——これが今回2パターンに絞った目的。
3. **パターンA・Bが同時に同方向で成立した場合、合計リスクが2%を大きく超えないように調整する**（片方のロットを減らす、または片方のみ取る）。
4. **トレード日誌をつけ、月末に勝率・期待値R・PFを実トレードで集計** し、`reports/backtest_results.csv`の数値（A: 勝率41.4%・期待値+0.160R、B: 勝率52.6%・期待値+0.379R、いずれもグロス）と比較する。乖離が大きい場合はブローカーのスプレッド・約定を疑う。
5. **レンジ相場（トレンドが崩れた局面）ではパターンAのブレイクアウトがダマシになりやすい。** 連敗が2〜3回続いたら日足のトレンド方向を再確認し、レンジ入りが疑われる間はロットを落とす。
6. まずはデモか最小ロットで1ヶ月運用し、上記の期待値通りになるか検証してから資金を増やす。
