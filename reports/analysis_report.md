# ゴールド / ドル円 チャートパターン検証レポート

**検証日**: 2026-08-23
**データ**: Yahoo Finance (`GC=F` ゴールド先物, `JPY=X` ドル円)
**期間**: 日足 約2年分(2024-08〜2026-08) / 1時間足 直近60日
**手法**: 4つの機械的な売買パターンを実際の価格データにバックテストし、勝率・期待値(R倍数)・プロフィットファクター・最大ドローダウンを算出。「勝てるパターン」を感覚ではなく数字で検証した。

再現コード: `src/` 以下（`data_fetch.py` → `run_analysis.py`）。誰でも再実行して検証可能。

---

## 1. 検証した4パターン

| 戦略 | ロジック |
|---|---|
| **トレンド押し目 (trend_pullback)** | EMA200で大局トレンドを判定し、EMA20がEMA50を押し目から再度クロスしたら順張りエントリー |
| **ドンチアン・ブレイクアウト (donchian_breakout)** | 過去20本の高値/安値を終値がブレイクしたら順張りエントリー（タートルズ手法） |
| **RSI逆張り (rsi_mean_reversion)** | 大局トレンド方向に沿って、RSIが30/70から戻ったところで逆張り気味に押し目/戻り売り |
| **ボリンジャーバンド逆張り (bollinger_reversion)** | ±2σを一旦外れて戻ってきたら中心線方向へ逆張り |

全戦略共通のリスク管理: 損切り=シグナル時点のATR(14)×1.5、利確=ATR×3.0（リスクリワード比1:2）、最大保有20本、シグナル後は次の足の始値でエントリー（先読みなし）。

## 3. 結論：統計的に信頼できるのはゴールドのブレイクアウトのみ

- **取引数が十分（15件以上）かつ期待値がプラス**なのは、実質的に **Gold × 日足 × ドンチアン・ブレイクアウト（27件, 勝率55.6%, 期待値+0.667R, PF2.5）** と、その1時間足版（45件, +0.306R）だけだった。
- トレンド押し目やRSI逆張りは高い期待値を示した組み合わせもあるが、**取引数が2〜5件しかなく統計的に無意味**（1〜2回勝っただけで期待値が跳ね上がる）。参考程度に留めるべき。
- **ドル円は今回検証した4パターンいずれも、十分な取引数があるものは軒並み期待値マイナスかほぼゼロ**。この2年のドル円相場（レンジ〜緩やかなトレンド）ではシンプルな順張り/逆張りの機械的ルールでは優位性が出なかった。ドル円で戦うなら、この4パターン以外のアプローチ（ファンダメンタルズ、金利差、より高度なフィルター）が必要。
- 年別に分解すると、Gold日足ブレイクアウトは 2024年（−0.4R, 5件）で不調、2025年（+1.08R, 13件）2026年（+0.67R, 9件）で好調——**強いトレンド相場でこそ機能する順張り手法**であり、レンジ相場では機能しないことも確認できた。万能パターンではない。

### 実践的な売買ルール（検証で優位性が確認できたもの）

**ゴールド（XAU/USD）日足ドンチアン・ブレイクアウト**
1. 過去20日の高値・安値を毎日更新して監視
2. 終値が過去20日高値を上抜けたら **翌日の寄り付きで買い**、終値が過去20日安値を下抜けたら **翌日の寄り付きで売り**
3. 損切り: エントリー時点のATR(14)×1.5
4. 利確: エントリー時点のATR(14)×3.0（リスクリワード1:2）
5. 20営業日以内に決着しなければ成行決済
6. 逆シグナルやポジション保有中の新シグナルは無視（同時に1ポジションのみ）

## 4. 重要な限界・注意点（誇張しないために）

- **スプレッド・手数料・スワップは未計算。** 特に1時間足は損切り幅が小さくなるため、実際のコストで期待値が目減りする。日足の方がコスト耐性は高い。
- **サンプル数がまだ少ない**（27件）。統計的には方向性を示す材料であり、「絶対に勝てる」証拠ではない。継続的な検証（ウォークフォワード）が必要。
- 過去の成績は将来の成績を保証しない。2024年のように機能しない期間もある。
- 本レポートは教育・分析目的であり、投資助言ではない。実資金投入は自己責任で。

## 5. 「月100万円」を狙うための現実的な資金計画

検証で確認できた唯一の統計的優位性（Gold日足ブレイクアウト: 期待値+0.667R、月あたり約1.1回）と、より高頻度な1時間足版（期待値+0.306R、月あたり約22.5回）を使い、**月100万円の期待利益**を得るために必要な資金・リスク量を逆算した（`src/position_sizing.py`で再計算可能）。

| リスク/トレード | Gold日足(1.1回/月, 0.667R) 必要資金 | Gold1h(22.5回/月, 0.306R) 必要資金 |
|---:|---:|---:|
| 0.5% | 約2億6,700万円 | 約2,900万円 |
| 1.0% | 約1億3,300万円 | 約1,450万円 |
| 2.0% | 約6,700万円 | 約730万円 |
| 3.0%（推奨リスクを大幅超過） | 約4,400万円 | 約480万円 |

**率直な結論**: 健全なリスク管理（1トレードあたり1〜2%）の範囲で「月100万円」を安定的な期待値として狙うには、**最低でも数百万〜1千万円台の口座資金**が必要になる（1時間足の高頻度版でも1%リスクで約1,450万円）。これより少ない資金で月100万円を狙う場合、1トレードのリスクを吊り上げるしかなく、それは**期待値は同じでも破産リスク（ドローダウンで資金が壊滅する確率）が跳ね上がる**、極めて危険な運用になる。

### 現実的なロードマップ

1. **まず少額（例: 50〜150万円）で1%リスク運用を開始し、期待値を実弾で検証する。** 上記の1時間足戦略なら月あたり期待収益は「口座×1%×22.5回×0.306R ≒ 口座の6.9%」。150万円口座なら期待値ベースで月約10万円（ブレは大きい）。
2. **月100万円は「今月の目標」ではなく「資金が育った先のマイルストーン」と位置づける。** 複利で資金を育てる、または利益を追加入金して口座を大きくする。
3. **トレード頻度を増やす。** 銘柄をゴールド+ドル円+他の主要ペアに分散し、複数の時間足・複数パターンを組み合わせることで、1つのエッジに依存せず月間の期待R合計を積み増す（ただし各パターンは個別に検証・優位性確認したものに限る）。
4. **必ずトレード日誌をつけ、月次でこの検証と同じ指標（勝率・期待値R・PF・最大DD）を実トレードで再計算する。** バックテストと乖離があれば手法かコストの見直しサイン。
5. **リスクは1トレード1〜2%を厳守。** 3%を超えるリスクは、期待値がプラスでも数回の連敗で再起不能なドローダウンになり得る。
